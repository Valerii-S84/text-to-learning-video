# Fonts

`NotoSans-SemiBold.ttf` is the bundled production subtitle and intro-topic font. It is
distributed under the SIL Open Font License 1.1 in `OFL.txt`.

`DancingScript-SemiBold.ttf` is the bundled production intro-title font. It is distributed
under the SIL Open Font License 1.1 in `DancingScript-OFL.txt`.

FFmpeg receives this directory explicitly, so renders do not depend on host-installed fonts.
